== Sample Questions
We will have a short quiz about the topics you just read.
To prepare and check your own level of knowledge answer these questions.

=== World Wide Web General
. What are the most essential technologies that made the World Wide Web such a success?
- Storing, Updating and finding documents and data files.
. How are resources (html pages, images, etc) addressed on the web?
- Trough a URL that demonstrates the path of the stored html pages, images, etc
. What are the general components of a url?
- schemes, : , // , host , path , ? query , # , fragment

=== Web Server
. What is a web server?
- A web server is computer software that accepts requests via HTTP or HTTPS.
. What does a web server do?
- A web server Program implements one or more versions of HTTP Protocol in a client-server model.
. How can content be stored on a web server?
- by using filesystems and databases
. How is content in webpages described?
- static and  dynamic

=== Web Client
. What is a web client?
- It is an application for accessing websites
. What does a web client do?
- It fetches content and displays it on the user's device
. Are Web Client and Web Browser the same?
- No, the Web Browser is an application that is accessing websites and a Web CLient is responsible for retrieving and facilitating end-user interaction with Web content.
=== HTTP
. Which steps happen between entering a url and seeing the page?
- The client and servers are communicating by exchanging individual messages.
. What is an HTTP request, what is an HTTP response?
- Request consist of a client wanting to fetch a resource using Get.
. What is a status code? What do `200` and `404` mean?
- '200' means that the request to the server was successfully.
. Which resources does the browser request additionally after it has received the html page?
- it parses the document and automatically issues secondary HTTP requests for all referenced external assets and sub-resources.

=== Static and Dynamic Web Pages
. What is the difference between a static and a dynamically generated web page?
- A static web page is getting delivered to a web browser exactly as stored.
    and a dynamic web page is getting constructed at runtime.
. Which of the two do we build in this course?
- static web pages

=== Hello World
. What is the html head element?
- The <head> element is a container for metadata and is placed between the <html> tag and the <bode> tag.

-It means that the declaration type is not a html tag. It is an "information" to the browser about what document type to expect.

- <div>, <span>

- <em>, <strong>
